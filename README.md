# BIO CASEFILES — 사라진 신품종

중학교 생명기술 수업을 위한 2.5D 과학 수사 게임 시제품입니다. Node.js 22 이상에서 실행합니다. Three.js는 라이선스와 함께 vendor/에 포함되어 있어 별도 설치나 CDN 접속이 필요하지 않습니다.

```sh
npm start
```

기본 포트는 3000이며 PORT로 변경할 수 있습니다. GitHub Pages에서는 gh-pages 브랜치의 루트를 정적 배포합니다.

## 수사 흐름
현장의 물건을 관찰하고 시료를 확보해 PCR 증폭 후 별도 염기서열 분석을 수행합니다. 식물 시료의 분석 결과와 실험 기록, 출입·반출 정보, 기존 진술을 대조합니다. 방은 3D 도형·조명·그림자·제한된 시점 전환을 사용합니다. 조작법은 안내하지만 필수 조사 순서나 다음 물건을 강조하지 않습니다. 장비함과 시료 보관함은 수사 권한으로 조사할 수 있으며 DNA로 자물쇠를 여는 퍼즐은 없습니다.

상단 버튼:
- 사전 수사 자료: 네 인물의 특징, 업무, 진술, 사전 확인 정황, 담당 식물 시료의 기준 DNA 구간. 시작부터 열람 가능합니다. 식물 시료의 유전정보는 연구원 개인의 DNA가 아닙니다.
- 내 증거 보드: 직접 확보한 현장 기록, 검사 결과, 분석 기록만 표시합니다. 종류별 필터와 카드별 관련 인물·개인 메모를 제공합니다. 연결은 학생의 가설이며 앱이 범인을 자동 표시하지 않습니다.
- 보고서: 개인 근거와 과학적 원리, 시스템 분석, 해결 방안을 작성합니다.
- 화면 설정: 현장 밝기 60–180%, 오브젝트 이름표 표시를 조절합니다.

## 기록과 평가
브라우저 localStorage에 진행과 보고서·증거 메모가 저장됩니다. 서버 제출 기능은 없습니다. 수사 노트에서 JSON을 내려받아 별도 제출해야 합니다. 원자료와 학생의 가설 메모는 화면에서 구분됩니다. 공용 기기는 기록을 보관한 뒤 초기화하세요.

범인 선택은 정해진 해설과 비교하며 서술 답안은 자동 채점하지 않습니다. 메커니즘 30점, 시스템 30점, 탐구·해결 20점은 교사용 참고 기준입니다. 45분 수업 운영과 난이도는 실제 학급에서 추가 검증이 필요합니다. 정답은 클라이언트 소스에 포함되므로 현재는 형성평가용 시제품입니다.

## 과학적 가정
PCR은 표적 DNA를 증폭하며 염기 순서를 읽는 분석은 별도입니다. 짧은 구간 일치는 전체 유전체나 개인 신원을 확정하지 않습니다. 조직 배양은 이 연구소의 캘러스를 거치는 방법을 다루며 모든 방법에 일반화하지 않습니다. 생장점 이용이 바이러스 무감염을 보장하지는 않습니다. 실험 기록과 시료 비교를 통해 얻은 사실을 진술·정황에 연결해야 합니다.

이 사건은 범행 시간의 출입 경로가 통제되고 제시된 장치 기록이 신뢰 가능하다는 가상의 조건을 사용합니다. 현실 수사의 입증 기준을 그대로 재현하지 않습니다.

## 저장 항목
bio-room-v2: 현장 진행과 도구 / bio-case-001-v1: 발견 기록·분석·가설 메모·보고서 / bio-display-v1: 화면 설정. 예전 버전 진행은 유지됩니다. 수사 노트의 초기화는 진행과 보고서, 가설 메모를 함께 삭제합니다.

## 도트 지도와 현장 조사
처음에는 1280×854 캔버스에 표시하는 쿼터뷰 연구소와 수사관 캐릭터가 표시됩니다. WASD·방향키 또는 복도 바닥 클릭으로 이동하고, 문 앞에서 E나 조사 버튼을 눌러 상호작용합니다. 배양실에 들어가면 페이지 전체를 사용하는 1인칭 현장으로 들어갑니다. 분석실은 확보한 시료의 PCR 증폭과 별도 염기서열 분석을, 수사 본부는 용의자 자료 열람을 제공합니다. 증거 보드와 보고서도 지도에서 열 수 있습니다.

현장에서는 WASD 또는 방향키 이동, E 조사, I 또는 Esc로 도구·자료 메뉴를 여닫습니다. 상단의 연구소 지도 버튼으로 현장을 나갑니다. 인벤토리와 자료는 메뉴를 열 때만 표시됩니다. 기존 진행 기록은 유지됩니다.

PC에서는 화면 클릭으로 Pointer Lock을 요청합니다. 지원하면 중앙 조준점을 기준으로 마우스 이동량만큼 회전합니다. 지원하지 않는 브라우저에서는 화면 안의 커서 이동량을 사용하며 마우스를 멈추면 시선도 멈춥니다. 이 대체 방식은 화면 가장자리에서 더 회전하려면 커서를 옮겨야 하는 한계가 있습니다. 모바일에서는 드래그와 화면 이동 버튼을 사용합니다. 주변 패널을 숨기는 것과 브라우저의 Pointer Lock 지원 여부는 별개입니다.

`npm test`는 보행 가능 영역과 이동 충돌을 검사합니다. 실제 교실 기기와 내장 브라우저의 조작감은 별도 확인이 필요합니다.

## 배포 시 브라우저 캐시
JS/CSS를 변경한 후 `npm run build`를 실행하면 index.html의 자산 URL에 내용 기반 버전이 붙습니다. 같은 파일의 과거 캐시가 새 배포의 스크립트 대신 사용되는 것을 방지합니다. 화면 상단에는 현재 UI 릴리스 확인용 ‘화면 v4’가 표시됩니다. GitHub에 push한 사실만으로 Pages의 공개 배포 완료를 판단하지 마세요. 배포 상태 확인이 제한된 경우 그 사실을 별도로 안내합니다.

시점 전환으로 1인칭에 복귀할 때 플레이어 위치는 유지하고 시선은 정면(기본 수평각·수직각)으로 초기화합니다. 카메라 월드 행렬을 즉시 갱신해 중앙 조준점과 조사 광선이 같은 방향을 사용합니다. 마우스의 이전 기준점은 전환·화면 크기 변경 시 폐기합니다.

## 쿼터뷰 배경과 캐릭터
assets/research-quarter.png는 이 프로젝트를 위해 생성한 연구소 배경입니다. 기존 게임의 타일이나 이미지를 사용하지 않습니다. 방의 깊이와 조명을 표현하는 일러스트 기반 배경으로, 정통 픽셀 타일 아트와는 질감 차이가 있습니다. 1280×854 캔버스에 표시하며 복도의 이동 구역과 세 출입구 상호작용을 연결합니다. 실내 탐색은 배양실의 별도 1인칭 화면을 사용합니다.

character.js는 네 방향과 보행 위상에 따라 팔·다리·옷자락을 움직이고 대기 중 호흡과 눈 깜빡임을 표시합니다. 캐릭터는 기존 픽셀 스타일을 유지하며 배경과의 화풍 통일은 추가 작업이 필요합니다.
