# BIO CASEFILES
중학교 생명기술 수업을 위한 45분 수사 게임의 첫 시제품입니다. Node.js 22 이상에서 실행합니다. 3D 렌더링에는 저장소에 포함된 Three.js 모듈을 사용하며 별도 패키지 설치나 CDN 연결이 필요하지 않습니다.

```sh
npm start
```

기본 포트는 3000이며 PORT 환경 변수로 변경할 수 있습니다. 현장 탐색 → 분석 3개 → 용의자 대조 → 개인 보고서 순서로 진행합니다. 모바일 화면도 지원합니다.

## 수업 운영
도입 4분 / 탐색 8분 / 분석 14분 / 추리 7분 / 보고서 7분 / 해설 5분을 권장합니다. 실제 학급에서 시간과 난이도 검증은 아직 필요합니다. 힌트와 오답 재시도는 감점하지 않습니다. 평가 기준은 메커니즘 30점, 시스템 30점, 탐구·해결 20점의 교사 평가용이며 자동 채점하지 않습니다.

진행과 답안은 브라우저 localStorage에 저장되며 서버에는 제출되지 않습니다. 교사에게 전달하려면 JSON 기록을 내려받아 별도로 제출합니다. 최종 해설 확인 후에는 원래 답안을 내려받아 보관하고 수정본을 구분하세요. 온라인 성적 수집·로그인·교사 전용 정답 보호 기능은 아직 없습니다. 클라이언트 소스에서 정답을 확인할 수 있으므로 현재 버전은 형성평가 및 수업 실험에 적합합니다.

## 과학·사건 설정
PCR 증폭과 염기서열 분석을 구분합니다. 제시된 짧은 서열의 일치를 전체 유전체 일치나 개인 신원 확인으로 해석하지 않습니다. 조직 배양의 생장점 이용은 바이러스 무감염을 보장하지 않습니다. 이 사건은 캘러스를 거치는 배양 방법을 사용한다고 명시합니다. 재조합 플라스미드 제작과 식물체 재생은 별도입니다.

사건에는 모든 경로가 통제되고 기록이 신뢰 가능하다는 가정이 명시됩니다. DNA 분석으로 바꿔치기를 확인하고, 출입 가능자·반출 검사·모순 진술을 결합해 민도현을 특정합니다. 현실 수사의 증거 기준을 그대로 재현하는 것은 아닙니다.

## GitHub Pages 배포
`gh-pages` 브랜치의 루트에 정적 파일을 배포합니다. GitHub 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch, gh-pages, / (root)를 선택하고 Save를 누릅니다. GitHub가 표시하는 배포 완료 상태와 주소를 확인하세요. Node 서버 없이 index.html, style.css, app.js로 동작합니다. 로그인이나 학생 답안 서버 전송은 없습니다.


## 2.5D 탐색 버전
첫 화면은 실제 3D 도형·조명·그림자와 제한된 시점 전환을 사용하는 방입니다. 물건 클릭 → 카메라 접근 → 확대 조사, 도구 수집·선택·사용, 서랍 잠금, 보관함 열기, 배양 공정 복원, PCR 증폭 후 별도 시퀀싱 흐름을 제공합니다. 실험 노트에서 재조합 기록을 복원합니다. 수사 노트 버튼으로 기존 진술·학습 참고·개인 보고서 화면을 엽니다. 이 버전은 Doors & Rooms 계열의 조작 흐름을 참고한 독자적인 저폴리곤 시제품이며, 해당 게임의 이미지나 모델을 사용하지 않습니다.

WebGL을 지원하는 최신 브라우저가 필요합니다. 방의 진행은 `bio-room-v2`, 보고서는 `bio-case-001-v1` localStorage 항목에 저장됩니다. 수사 노트의 초기화는 두 진행 기록을 함께 초기화합니다. Three.js 라이선스는 vendor/THREE-LICENSE.txt에 포함합니다.

## 화면과 조작 안내
방·수사 길잡이·인벤토리는 각각 별도 영역에 배치됩니다. 모든 조사 대상에 이름표와 연결선을 표시하며, 금색은 다음 목표, 파란색은 선택한 도구를 사용할 대상입니다. 화면 설정에서 이름표 표시를 조절할 수 있습니다. 다음 목표와 도구 사용 대상은 이름표를 꺼도 남습니다.

길잡이는 노트 읽기, 재조합 기록, 서랍, 시료 확보, 조직 배양, PCR, 염기서열 해석, 출입 기록까지 8단계의 진행을 보여줍니다. 처음 접속 시 사건과 조작 안내가 표시됩니다. 인벤토리는 수집 전 빈 슬롯과 수집 후 도구 그림, 선택 상태 및 사용처를 보여줍니다. 확대 조사 그림은 별도로 제작한 SVG이며, 열린 서랍·보관함에는 내부 물건을 표시합니다.

화면 설정의 현장 밝기는 60–180% 범위이며 UI 글자의 밝기에는 영향을 주지 않습니다. 밝기와 이름표 설정은 `bio-display-v1`에 저장됩니다. 실제 학급의 기기 화면 및 교실 조명에서 추가 확인이 필요합니다.
