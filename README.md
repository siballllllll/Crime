# BIO CASEFILES
중학교 생명기술 수업을 위한 45분 수사 게임의 첫 시제품입니다. Node.js 22 이상에서 외부 패키지 없이 실행합니다.

```sh
npm start
```

기본 포트는 3000이며 PORT 환경 변수로 변경할 수 있습니다. 현장 탐색 → 분석 3개 → 용의자 대조 → 개인 보고서 순서로 진행합니다. 모바일 화면도 지원합니다.

## 수업 운영
도입 4분 / 탐색 8분 / 분석 14분 / 추리 7분 / 보고서 7분 / 해설 5분을 권장합니다. 실제 학급에서 시간과 난이도 검증은 아직 필요합니다. 힌트와 오답 재시도는 감점하지 않습니다. 평가 기준은 메커니즘 30점, 시스템 30점, 탐구·해결 20점의 교사 평가용이며 자동 채점하지 않습니다.

진행과 답안은 브라우저 localStorage에 저장되며 서버에는 제출되지 않습니다. 교사에게 전달하려면 JSON 기록을 내려받아 별도로 제출합니다. 최종 해설 확인 후에는 원래 답안을 내려받아 보관하고 수정본을 구분하세요. 온라인 성적 수집·로그인·교사 전용 정답 보호 기능은 아직 없습니다. 클라이언트 소스에서 정답을 확인할 수 있으므로 현재 버전은 형성평가 및 수업 실험에 적합합니다.

## 과학·사건 설정
PCR 증폭과 염기서열 분석을 구분합니다. 제시된 짧은 서열의 일치를 전체 유전체 일치나 개인 신원 확인으로 해석하지 않습니다. 조직 배양의 생장점 이용은 바이러스 무감염을 보장하지 않습니다. 이 사건은 캘러스를 거치는 배양 방법을 사용한다고 명시합니다. 재조합 플라스미드 제작과 식물체 재생은 별도입니다.

사건에는 모든 경로가 통제되고 기록이 신뢰 가능하다는 가정이 명시됩니다. DNA 분석으로 바꿔치기를 확인하고, 출입 가능자·반출 검사·모순 진술을 결합해 민도현을 특정합니다. 현실 수사의 증거 기준을 그대로 재현하는 것은 아닙니다.

## GitHub Pages 배포
`gh-pages` 브랜치의 루트에 정적 파일을 배포합니다. GitHub 저장소 Settings → Pages → Build and deployment에서 Deploy from a branch, gh-pages, / (root)를 선택하고 Save를 누릅니다. GitHub가 표시하는 배포 완료 상태와 주소를 확인하세요. Node 서버 없이 index.html, style.css, app.js로 동작합니다. 로그인이나 학생 답안 서버 전송은 없습니다.
